# Project Requirements Checklist

Source: COMP3211 Course Project Description, Fall 2026.

## User stories

- [ ] **US1:** Manage different types of personal information records (PIRs) in one location.
- [ ] **US2:** Create plain-text notes.
- [ ] **US3:** Create tasks with descriptions and deadlines.
- [ ] **US4:** Create events with descriptions, starting times, and alarms.
- [ ] **US5:** Create contacts with names, addresses, and mobile numbers.
- [ ] **US6:** Modify data in existing PIRs.
- [ ] **US7:** Search by record type and field data, including text containment, time `<`, `>`, `=`, and compound conditions using `&&`, `||`, and `!`.
- [ ] **US8:** Print detailed information about one PIR or all PIRs.
- [ ] **US9:** Delete a specified PIR.
- [ ] **US10:** Store PIRs in a file with the `.pim` extension.
- [ ] **US11:** Load PIRs from a `.pim` file.

## Required implementation constraints

- [ ] The application runs through a command-line interface.
- [ ] Model code is in a separate package named `model`.
- [ ] The implementation uses only Python standard-library modules.
- [ ] Model unit tests execute automatically and pass.
- [ ] Model line coverage is recorded in a separate report.
