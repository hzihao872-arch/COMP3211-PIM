# Honour Declaration

Use the official `Honour Declaration for Group Project` form supplied by the course or university. The completed declaration must be placed in the root of the final ZIP even if the group did not use GenAI.

Before signing, confirm:

- every member name and student ID is correct;
- contribution percentages are agreed and recorded;
- GenAI-assisted content is acknowledged accurately;
- all required signatures or confirmations are present.

Do not replace the official form with this README.
