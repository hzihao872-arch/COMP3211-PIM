# Design Document

## Cover page

- Course, project, group, members, version, and date

## 1. Introduction

Summarize the design goal and its relationship to the SRS.

## 2. Architecture

- Architecture diagram
- Selected generic architectural pattern
- Why it fits this PIM
- How CLI, controller, model, and storage instantiate the pattern

## 3. Main code components

Include diagrams showing the structure and relationships among the main components.

For every important class, document:

- responsibility;
- fields;
- public/protected methods;
- return type;
- method name;
- argument names and types;
- declared or expected exceptions.

## 4. Search-and-update example

Include a sequence or activity diagram showing a user defining a criterion, searching for PIRs, selecting a result, and updating it.

## 5. Diagram explanations

Explain every diagram, symbol, relationship, and important design choice in text.

## Review checklist

- [ ] Architecture diagram included and explained
- [ ] Main components and relationships included
- [ ] Method signatures and exceptions documented
- [ ] Search-and-update sequence/activity diagram included
- [ ] Diagrams agree with the current source code
